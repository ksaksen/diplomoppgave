# diploma thesis
The goal of this project is 

1) to use scans of my diploma thesesis from 1996 to produce a good markdown representation
2) to use the markdown as input to an AI in order to produce a python script that can do similar simulations as were done in 96
3) to use the markdown to produce human readable pdf dokuments
4) the project might also add docosaurus ot make md files available online 

## gemini
the project uses gemini and md files are produced with a python script that sends pictures and instructions to gemini

### latex 
equations and stuff that once were written in latex is reproduced in markdown in a way that reqiures a latex/katex plugin 

### drawings
graphs and sketches are NOT yet included in a good way - the goal is to make tekst representations that is usable for an AI and that looks good and that gives human readers an intiutive understanding of complex problems
